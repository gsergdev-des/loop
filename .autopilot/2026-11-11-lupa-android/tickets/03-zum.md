## Что должно заработать

Картинку можно увеличивать четырьмя способами: ползунком над будущими кнопками, щипком двумя пальцами, кнопками громкости (если опция включена) и двойным тапом, который возвращает к значению по умолчанию. Шкала одна, от ×1 до максимума камеры этого телефона, и сверху ещё до ×2 программного увеличения превью.

Вверху крупно виден итоговый зум «×4.0» на полупрозрачной подложке. Он не залезает под статус-бар и вырез камеры. При запуске зум такой же, как в прошлый раз (при самом первом запуске ×2), или фиксированный — смотря что выбрано в настройках. Каждое изменение запоминается.

## Из брифа, дословно

> «Зум. От ×1 до максимума камеры (`zoomState.maxZoomRatio`). Плавное изменение ползунком и щипком. Если оптического/цифрового зума камеры не хватает — дополнительный программный зум превью до ×2 сверху. По умолчанию при запуске — последнее использованное значение.»
> «Верх: только индикатор зума (например, «×4.0») крупным шрифтом, полупрозрачная подложка.»
> «Над кнопками: горизонтальный ползунок зума на всю ширину, высота зоны касания не меньше 64 dp.»
> «щипок — зум; … двойной тап — сброс зума к значению по умолчанию; кнопка громкости «+»/«−» — зум (включается в настройках).»
> «Нет телевика. Зум цифровой (кроп основной камеры); максимум брать из `maxZoomRatio` устройства, не хардкодить.»
> «индикатор зума — по `statusBars`»
> «Зум при запуске: последний / фиксированный (×2 по умолчанию)» · «Приложение запоминает между запусками: последний зум»

## Критерии приёмки

- [ ] `ZoomMath` ровно по `interfaces.md`, юнит-тесты: `split` (ниже и выше максимума камеры), `maxTotal`, логарифмические `toSlider`/`fromSlider` (взаимно обратные, концы 0 и 1), ряд шагов 1 → 1.5 → 2 → 3 → 4 → 5 вверх и обратно вниз с прижатием к границам, `format` (`×4.0`, `×12.5`, точка при любой локали), `unscaleTap`.
- [ ] Индикатор (`zoomIndicator`) вверху по центру: ≥ 28 sp жирный, полупрозрачная тёмная подложка, отступ сверху по `statusBars ∪ displayCutout`. Больше ничего наверху нет.
- [ ] Ползунок (`zoomSlider`) на всю ширину минус поля 16 dp, зона касания ≥ 64 dp, логарифмическая шкала. Отступ снизу по `navigationBars` (кнопки таска 04 встанут под ним).
- [ ] Итоговый зум в диапазоне ×`max(1, minZoom)`…`maxTotal`. Камера получает `split().cameraRatio`, `PreviewView` масштабируется на `softScale` вокруг центра. VM-тест с фейковой камерой: зум выше максимума камеры даёт `setZoomRatio(max)` и `softScale > 1`.
- [ ] Щипок по превью умножает зум на коэффициент жеста; двойной тап ставит `settings.fixedZoom` (прижатый к максимуму). VM-тесты на оба.
- [ ] Кнопки громкости: при `settings.volumeKeysZoom` на экране лупы `+`/`−` шагают зум, событие съедается (громкость не меняется), удержание повторяет шаг. Опция выключена → `onVolumeKey` возвращает `false`, и Activity отдаёт событие системе. VM-тест на оба случая.
- [ ] Зум при запуске = `launchZoom(settings, remembered)`, прижатый к диапазону после первого `Ready`. На каждом `Ready` зум камеры применяется заново. Каждое изменение зума пишется `rememberZoom` с задержкой ~300 мс. VM-тесты: LAST с сохранённым ×5 → ×5; первый запуск → ×2; FIXED ×3 → ×3; ×50 при максимуме ×20 → ×20.
