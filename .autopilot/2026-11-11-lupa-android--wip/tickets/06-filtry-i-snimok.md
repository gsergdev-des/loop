## Что должно заработать

Кнопка «Фильтр» переключает по кругу Обычный → Высокий контраст → Ч/Б → Инверсия → Жёлтый на чёрном. Название фильтра на секунду появляется крупно по центру, а кнопка залита, пока фильтр не «Обычный». Фильтр действует сразу и на живую картинку (без тормозов: считается на видеокарте), и на стоп-кадр. Последний фильтр запоминается между запусками.

Кнопка «Снимок» сохраняет в галерею, в папку Pictures/Lupa, ровно то, что сейчас видно на экране, вместе с фильтром. В живом режиме — свежий снимок, обрезанный по программному зуму, на стоп-кадре — его видимую часть. После этого на полторы секунды видно «Сохранено» или «Не удалось сохранить». Пока идёт сохранение, повторные нажатия не плодят копий. Разрешений на хранилище не нужно.

## Критерии приёмки

- [ ] `Filters` по `interfaces.md`, матрицы по формулам из спецификации. Юнит-тесты на `matrix`, применённую к цвету: Обычный не меняет цвет; Ч/Б даёт R=G=B; Инверсия белое → чёрное; Жёлтый на чёрном: белое → чёрное, чёрное → жёлтое (R=G≈255, B=0); Высокий контраст: серый 128 остаётся ≈128, 160 становится светлее.
- [ ] `onFilterClick` → `filter.next()`, `message = FilterName(filter)` (снимается через 1 с), `rememberFilter` с задержкой. Последний фильтр восстанавливается из `remembered.lastFilter` при запуске. Превью: `Filters.applyTo(previewView, filter)` (RenderEffect на API 31+, слой с ColorMatrixColorFilter на 29–30). Стоп-кадр: `colorFilter(filter)` на `frozenImage`. Кнопка `btnFilter` залита, если фильтр не NORMAL. Названия — «Обычный», «Высокий контраст», «Ч/Б», «Инверсия», «Жёлтый на чёрном», ≥ 32 sp по центру (`filterName`). Тесты: VM — порядок по кругу и сообщение; Compose — после нажатия видно название.
- [ ] `MediaStoreSnapshotSaver` — `Pictures/Lupa`, JPEG 92, `IS_PENDING` на время записи, имя `Lupa_yyyyMMdd_HHmmss.jpg`; ошибка → `Result.failure`. Robolectric-тест: после `save` в MediaStore есть запись с `RELATIVE_PATH` `Pictures/Lupa/` и MIME `image/jpeg`.
- [ ] `onSnapshotClick`: живой режим → `capture()` → `centerCrop(softScale)` → `Filters.applyTo(bitmap, filter)` → `saver.save`; на стоп-кадре → `visibleRect(viewport)` → фильтр → `save`. `busy = SAVING` на время работы, повторные нажатия игнорируются. Успех → `message = Saved` (~1,5 с, текст «Сохранено»), ошибка захвата или записи → `SaveFailed` («Не удалось сохранить»). VM-тесты с фейковыми камерой и сохранением: обе ветки, обрезка по `softScale = 2` даёт половинные размеры, фильтр применён.
- [ ] В манифесте не появилось новых разрешений: `tools/check_apk.py` зелёный.
