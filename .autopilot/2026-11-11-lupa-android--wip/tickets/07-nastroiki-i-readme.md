## Что должно заработать

Маленькая шестерёнка в правом углу зоны управления, над ползунком, открывает простой экран настроек — один список. В нём:
- «Включать фонарик при запуске»;
- «Зум кнопками громкости»;
- «Зум при запуске: последний / фиксированный» с выбором ×1.5 / ×2 / ×3 / ×4;
- «Не гасить экран, пока открыта лупа»;
- «Вибрация при нажатии»;
- «Размер кнопок: обычный / крупный».

Изменения действуют сразу и сохраняются. «Назад» возвращает в лупу.

Нажатия кнопок ощущаются короткой вибрацией, пока она включена. Пока открыта лупа, экран не гаснет, если так выбрано. Крупный размер делает кнопки выше, а иконки и подписи — больше.

README по-русски объясняет:
- как собрать APK одной командой;
- как поставить его через `adb install` или просто скопировав файл на телефон;
- что включить на HyperOS;
- как создать свой ключ подписи.

## Критерии приёмки

- [ ] Шестерёнка `btnSettings` (иконка ~48 dp, своя векторная) — в правом углу зоны управления над ползунком, не наверху. Открывает `SettingsScreen` (`settingsScreen`) со стрелкой «назад»; системный «назад» возвращает в лупу. На главном экране по-прежнему ровно 4 большие кнопки + шестерёнка.
- [ ] `SettingsScreen` — один список из шести пунктов в порядке брифа, строки ≥ 64 dp, тексты ≥ 16 sp. Четыре переключателя, «Зум при запуске» (Последний / Фиксированный и, при фиксированном, выбор ×1.5 / ×2 / ×3 / ×4), «Размер кнопок» (Обычный / Крупный). Значения по умолчанию как в брифе. Каждое изменение сразу пишется через `SettingsRepository.update`. Compose-тесты: все шесть пунктов видны; переключение вызывает изменение настроек.
- [ ] Вибрация: при `settings.haptics` нажатие любой из 4 кнопок и шестерёнки вызывает `performHapticFeedback(VIRTUAL_KEY)`; выключено — не вызывает. Разрешение `VIBRATE` не добавлено (`tools/check_apk.py` зелёный).
- [ ] «Не гасить экран»: `FLAG_KEEP_SCREEN_ON` стоит, пока показан экран лупы и `keepScreenOn`, и снят на экране настроек и при выключенной опции. Robolectric-тест на флаг окна.
- [ ] Размер кнопок: NORMAL — высота 80 dp, иконка 36 dp, подпись 16 sp; LARGE — 96 dp, 44 dp, 18 sp. Compose-тест: в LARGE кнопка ≥ 96 dp в высоту.
- [ ] `README.md` по-русски: что это; требования (JDK 17+, Android SDK platform 36 / build-tools 36.0.0, `ANDROID_HOME` или `local.properties`); сборка `./gradlew assembleRelease` и путь к APK; установка `adb install -r …`; шаги HyperOS из брифа дословно и вариант «скопировать APK и открыть файлом»; создание своего ключа (`keytool -genkeypair …` и формат `keystore.properties` без настоящих значений) и что без него APK подписан отладочным ключом; как посмотреть время старта и fps (`adb logcat -s Lupa`); команда проверки.
