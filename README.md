# Лупа

Офлайн-лупа для Android на камере телефона: зум, фонарик, стоп-кадр, цветовые фильтры и сохранение снимка в галерею. Крупные кнопки под большой палец, тёмный интерфейс. Без рекламы, аналитики и сетевых библиотек; в манифесте единственное разрешение — доступ к камере (`INTERNET` не объявлен). Приложение сделано для личного использования и ставится из APK-файла, без Google Play.

Что умеет:

- зум ползунком, щипком и кнопками громкости (если включено в настройках), двойной тап возвращает зум по умолчанию;
- фонарик, тап по картинке наводит фокус;
- «Стоп-кадр» замораживает чёткий снимок, его можно увеличить до ×8 и двигать пальцем;
- «Фильтр» переключает по кругу: Обычный, Высокий контраст, Ч/Б, Инверсия, Жёлтый на чёрном;
- «Снимок» сохраняет то, что на экране (с фильтром), в папку `Pictures/Lupa`;
- настройки (шестерёнка над ползунком): фонарик при запуске, зум кнопками громкости, зум при запуске (последний или фиксированный), «не гасить экран», вибрация при нажатии, размер кнопок.

## Требования для сборки

- JDK 17 или новее;
- Android SDK: platform 36 и build-tools 36.0.0;
- путь к SDK: переменная `ANDROID_HOME` или файл `local.properties` в корне проекта со строкой `sdk.dir=/путь/к/Android/sdk` (файл в `.gitignore`);
- интернет при первой сборке: Gradle скачивает зависимости.

## Сборка

Одна команда:

```
./gradlew assembleRelease
```

Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

Если своего ключа подписи нет, APK подписывается стандартным отладочным ключом, а в выводе сборки будет предупреждение. Такой файл нормально ставится на телефон; свой ключ нужен, только если вы хотите подписывать своим (см. «Свой ключ подписи»).

## Установка

### Через `adb`

На телефоне включите отладку по USB (см. «Настройка HyperOS»), подключите его кабелем и выполните:

```
adb install -r app/build/outputs/apk/release/app-release.apk
```

`-r` ставит поверх уже установленной версии.

### Копированием файла

Скопируйте `app-release.apk` на телефон (кабелем, через облако или мессенджер) и откройте его в файловом менеджере. Системе придётся разрешить установку из этого источника.

## Настройка HyperOS (Redmi Note 13 Pro 5G)

В «Для разработчиков» включить «Отладка по USB» и «Установка через USB»; второе требует входа в Mi-аккаунт. Альтернатива — скопировать APK на телефон и открыть файлом.

При первом запуске приложение просит доступ к камере. Если вы отказали, лупа покажет объяснение и кнопку «Открыть настройки».

## Свой ключ подписи

1. Создайте ключ (команда спросит пароли и ваши данные; запомните их, ключ потом не восстановить):

   ```
   keytool -genkeypair -v -keystore lupa-release.jks -alias lupa -keyalg RSA -keysize 2048 -validity 10000
   ```

2. В корне проекта создайте файл `keystore.properties`:

   ```
   storeFile=lupa-release.jks
   storePassword=ПАРОЛЬ_ХРАНИЛИЩА
   keyAlias=lupa
   keyPassword=ПАРОЛЬ_КЛЮЧА
   ```

   `storeFile` — путь от корня проекта или абсолютный. Нужны все четыре значения, иначе сборка остановится с понятной ошибкой.

3. Соберите `./gradlew assembleRelease`. Теперь APK подписан вашим ключом.

Файлы `keystore.properties`, `*.jks` и `*.keystore` перечислены в `.gitignore`, в репозиторий они не попадают. Храните ключ и пароли отдельно и не публикуйте их. Подпись должна совпадать у всех версий: APK, подписанный другим ключом, не встанет поверх установленного, его придётся сначала удалить с телефона.

## Время старта и fps

Лупа пишет в Logcat под тегом `Lupa` время от старта процесса до первого кадра и частоту кадров (раз в 5 секунд):

```
adb logcat -s Lupa
```

## Проверка

Тесты и сборка release-APK, затем проверка результата (размер APK не больше 10 МБ, в манифесте только разрешение камеры, нет запрещённых библиотек):

```
./gradlew --no-daemon testDebugUnitTest assembleRelease && python3 tools/check_apk.py
```

Тесты идут на JVM (Robolectric), без телефона и эмулятора, поэтому работу камеры, фонарика, вибрации и скорость фильтров нужно проверять на самом телефоне.
